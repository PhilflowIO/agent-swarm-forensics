# The export does not live here

This directory is intentionally empty. The wiki export is not ours to redistribute.
Download it from its authors at <https://collusion.wiki/explorer/download.html> and
unpack it here, then verify it against `SHA256SUMS` (the sums of the copy every number
in the paper was computed from).

Expected files: `revisions.jsonl`, `pages.jsonl`, `events.jsonl`, `labels.jsonl`,
`manifest.json`.
